# FingerCanvas-Instant-Digital-Sketchpad
Finger Canvas is an interactive drawing application that allows users to draw on their computer screen using finger tracking technology through a webcam. This innovative tool leverages computer vision techniques to enable touch-free drawing, making it an engaging and fun application for users of all ages.

**Features**

Finger Tracking: Detects finger movements using MediaPipe for real-time drawing.

Dynamic Canvas: Users can draw on a digital canvas displayed on the screen.

Gesture Control: Supports simple gestures to control brush size, color, and eraser mode.

Real-Time Performance: Provides a smooth and responsive drawing experience.

**Technologies Used**

Python: The primary programming language used for the project.

OpenCV: For real-time webcam video capture and image processing.

MediaPipe: For hand and finger tracking to detect user gestures.

NumPy: For efficient numerical operations.

Object-Oriented Programming (OOP): To ensure modularity and code reusability.

**How It Works**

Startup:

Launch the script to start the webcam feed.

A digital canvas appears on the screen.

Drawing:

Use your index finger to draw on the canvas. The application tracks your finger’s movement in real time.

Gestures:

Switch Colors: Use a specific gesture to change the drawing color.

Adjust Brush Size: Another gesture to increase or decrease the brush size.

Eraser Mode: Activate the eraser to remove unwanted parts of the drawing.

Exit:

Press q to quit the application.
